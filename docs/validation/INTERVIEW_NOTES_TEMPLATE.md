## 4. Incident evidence table

Use one row per distinct past incident. A general opinion is not an incident.

| Incident ID | Event context | Missing/late element | Dependency or affected work | Observable consequence | Workaround | Evidence strength (0-3) |
|---|---|---|---|---|---|---:|
| `[INC-___]` | | | | | | |

Evidence strength:

- `0` — no incident; only a general opinion or prediction.
- `1` — vague past example without a clear sequence or consequence.
- `2` — specific past incident with element, timing, and consequence.
- `3` — specific incident supported by an anonymized artifact or corroborating record voluntarily shown.

## 6. Statements classified by evidence status

| Statement | Classification | Basis |
|---|---|---|
| | `validated evidence / participant report / hypothesis / interviewer inference / unknown` | |

Rules:

- A participant report is evidence that the participant said or experienced something; it is not automatically evidence that all users behave the same way.
- An interviewer interpretation remains an inference until checked.
- Do not turn multiple anecdotes into a percentage unless the denominator and coding method are recorded in the scorecard.
